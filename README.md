# 助け舟

**▶ 遊ぶ: https://katomi95.github.io/tasukebune/**

善意100%・配慮0%の海難救助訓練。
港町の海難救助訓練に、手配ミスで超大型救助船が来てしまった――という設定の、1プレイ90秒のブラウザゲームです。溺れ役の参加者の救助はちゃんと成功しますが、そのたびに周りが少しずつひどいことになります。
訓練終了後には、参加者たちが船長に「殺す気か！」「死ぬかと思った！」と詰め寄ります（死者はゼロです）。

## 遊び方

上のURLか、`index.html` をブラウザで開くだけで遊べます（PCブラウザ推奨。外部ライブラリ・画像・音声ファイルは使っていません）。

| 操作 | キー |
|---|---|
| 前進・後退 | ↑↓ / W S |
| 旋回 | ←→ / A D |
| ブレーキ | Space |
| 救助棒 | 左クリック / Z（Z は最寄りの要救助者を自動で狙う） |
| 浮き輪 | 右クリック / X（X は最寄りの要救助者を自動で狙う） |
| 一時停止 | Esc / P |
| 消音 | M |

## ルール

- 制限時間90秒で、溺れ役の参加者をできるだけ多く救助する
- 船は慣性が強い。速く近づくと波で人が流れていく
- 止まっていたりぐるぐる回ったりすると渦が出る（渦は人を引き寄せるが、周りに迷惑がかかる）
- 低速（速力ゲージが緑）で船体をそっと当てると、そのまますくい上げられる
- 救助棒は速度が出ていると頭を小突く。浮き輪は船が動いていると狙いがズレる
- 波・渦・衝突による被害は「はた迷惑ポイント」として加算される
